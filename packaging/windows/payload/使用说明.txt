AnimaVN 整合包

【开始玩】
双击 AnimaVN.bat。会弹出一个黑窗口，等它说「好了」，浏览器会自己打开游戏。
第一次启动要解压、准备，大概一两分钟；以后十几秒。玩完关掉黑窗口就是退出。

第一次进游戏：右上角「API 设置」填一个模型 API（DeepSeek、中转站都行），
然后点顶栏「视觉小说」→「角色」，自带的 DeepSeek娘可以直接开始。

【更新】
先关掉游戏的黑窗口，再双击「更新.bat」。它会自己去找新版，只换程序，存档不动。

【手机上玩】
电脑开着游戏，手机连同一个 Wi-Fi，打开黑窗口里写的那个「手机」地址。
第一次 Windows 防火墙问要不要放行 Python，选「专用网络」。

【存档在哪】
AnimaBackend\data 这个文件夹。换电脑、重下整合包时，把它整个拷过去就行。
游戏里 设置 → 数据 →「现在备份」也能手动备份。

【常见问题】
- 双击后 Windows 说「无法验证发布者」或「已保护你的电脑」：点「更多信息」→「仍要运行」。
- 别放在 C:\Program Files 这类要管理员权限的文件夹里，放桌面或 D 盘都行。
- 黑窗口一闪就没了、或者报错：把窗口截图发给作者，或者到 GitHub 提 issue：
  https://github.com/JayziLi/AnimaVN-public/issues
- 语音、生图怎么接：https://github.com/JayziLi/AnimaVN-public 里的说明。

AnimaVN 整合包

【开始玩】
双击 AnimaVN.bat，打开 AnimaVN 启动器。第一次会先弹一个黑窗口解压，大概一两分钟，解完它自己关掉。
等启动器里「开始游戏」亮了点它，游戏在默认浏览器里打开。
勾上按钮下面的「全屏启动」，就改成全屏开游戏自己的窗口，F11 或 Alt+Enter 退出全屏。
启动器和游戏都关掉就是退出。

第一次进游戏：游戏左上角「模型」（或者 Esc 菜单 →「模型」）填一个模型 API（DeepSeek、中转站都行），
然后标题画面点「角色」，自带的 DeepSeek娘可以直接开始。

【更新】
先关掉启动器和游戏窗口，再双击「更新.bat」。它会自己去找新版，只换程序，存档不动。

【手机上玩】
电脑开着启动器，手机连同一个 Wi-Fi：点「开始游戏」旁边的齿轮 →「手机扫码玩」，扫二维码；
或者在手机浏览器里打开启动器首页右下角写的局域网地址。
第一次 Windows 防火墙问要不要放行 Python，选「专用网络」。

【存档在哪】
AnimaBackend\data 这个文件夹。换电脑、重下整合包时，把它整个拷过去就行。
游戏里 设置 → 数据 →「现在备份」也能手动备份。

【常见问题】
- 双击后 Windows 说「无法验证发布者」或「已保护你的电脑」：点「更多信息」→「仍要运行」。
- 别放在 C:\Program Files 这类要管理员权限的文件夹里，放桌面或 D 盘都行。
- 启动器卡住或者报错：左边「控制台」页有后台的输出，常见的报错会翻成大白话。
- 解压的黑窗口一闪就没了、或者报错：把窗口截图发给作者，或者到 GitHub 提 issue：
  https://github.com/JayziLi/AnimaVN/issues
- 语音、生图怎么接：https://github.com/JayziLi/AnimaVN 里的说明。

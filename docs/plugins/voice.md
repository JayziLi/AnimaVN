# 接入语音

不接语音也能玩，只是角色不出声。想让角色念台词，要先开着 GPT-SoVITS，再到 AnimaVN 里接上。

## 要准备

- 一台有 NVIDIA 显卡的电脑，可以就是你玩的这台
- 角色的声音模型：一个 `.ckpt` 文件和一个 `.pth` 文件。网上有别人练好的，也可以用 GPT-SoVITS 自己练
- 角色的原声：每种情绪一段，每段 3 到 10 秒。文件名写成 `【情绪】原文.wav`，比如 `【害羞】べ、別に待ってたわけじゃないから….wav`。文件名里的原文要和音频里说的一字不差

情绪名尽量和立绘的表情名一样。比如立绘叫「害羞」，原声也用「害羞」，念台词的语气就会跟着表情变。

## 第 1 步：启动 GPT-SoVITS

1. 到 [GPT-SoVITS 的 Releases](https://github.com/RVC-Boss/GPT-SoVITS/releases) 下载 Windows 整合包。RTX 50 系显卡选名字带 `nvidia50` 的那个
2. 解压到路径里没有中文和空格的地方，比如 `D:\GPT-SoVITS`
3. 打开解压后的文件夹，在上面的地址栏里输入 `cmd` 回车，会弹出一个命令行窗口。在里面运行下面这一行：

   ```powershell
   runtime\python.exe api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS\configs\tts_infer.yaml
   ```

4. 用浏览器打开 <http://127.0.0.1:9880/docs>，能打开就说明启动好了

以后每次玩之前都要先开着 GPT-SoVITS。可以把上面那行命令存成一个 `.bat` 文件放在这个文件夹里，以后双击就能启动。

## 第 2 步：连上语音服务

游戏里按 Esc → 插件，点左边「全局」里的「语音服务」。

1. 点「+ GPT-SoVITS」
2. GPT-SoVITS 就开在这台电脑上的话，地址不用改，直接点「测试」。显示「通了」就接上了

## 第 3 步：导入角色的声音

游戏里按 Esc → 素材，点上面的「声音」。

1. 点左边的「导入 refs.json」，「语音服务」选刚加的那台
2. 把下面这段里的角色名、模型和原声路径换成你自己的，贴进去，点「导入」：

   ```json
   {
     "character": "角色名",
     "gpt_weights": "D:/AnimaVoice/角色名/角色名.ckpt",
     "sovits_weights": "D:/AnimaVoice/角色名/角色名.pth",
     "refs": [
       { "file": "D:/AnimaVoice/角色名/【微笑】おかえり、今日はどうだった？.wav" },
       { "file": "D:/AnimaVoice/角色名/【害羞】べ、別に待ってたわけじゃないから….wav" }
     ]
   }
   ```

   排第一的原声是默认语气。不想改这段 JSON，也可以点「新建声音」，在「声音设置」里填名字和两个权重的路径，再点「新增情绪」一段段贴原声的路径
3. 日语角色还要改语言：点开「声音设置」，「语言」选日语
4. 试听：在「试听」那里输一句台词，选一个情绪，点「合成」。哪个语气不对，就换那段原声。想调语速，在右边的「全局参数」里

## 第 4 步：给这张卡选音色

先进游戏、选好这张卡，再按 Esc → 素材 → 声音，选中刚导入的声音，点上面的「给她用」。

也可以直接点游戏右上角的语音小牌子，在「音色」那一行选。一张卡只用一个音色，选了就换掉原来的。

然后角色的台词就有声音了。旁白和你自己说的话不念。

音色的语言是日语，就自动变成日语配音、中文字幕，不用另外设置。只想看中文：游戏设置 → 文字 → 字幕，选「只显示中文」。

以后想换声音、试音：点游戏右上角的语音小牌子，再点「换声音 · 试音」。

## 语音在另一台电脑上

玩的电脑显卡不够、家里另一台有显卡的话，可以在那台上启动 GPT-SoVITS，再连过来。推荐用 Tailscale：

1. 两台电脑都装 [Tailscale](https://tailscale.com/)，登同一个账号
2. 在显卡那台运行 `tailscale serve --bg --tcp=9880 tcp://127.0.0.1:9880`
3. 在 AnimaVN 的 插件 → 语音服务 里，把地址改成 `http://显卡那台的名字.你的tailnet.ts.net:9880`

这时候，声音设置里的模型和原声路径，都要填显卡那台电脑上的路径。

## 常见问题

| 你看到的 | 怎么办 |
|---|---|
| 右上角写着「语音断了」 | GPT-SoVITS 没开，或者地址不对。用浏览器打开 `地址/docs` 看看 |
| 右上角写着「语音关」 | 点它，把「语音」开关打开。插件里「语音」那一行最右边的开关、游戏设置 → 声音 → 语音，都是同一个 |
| 角色不出声 | 这张卡还没选音色，照第 4 步选一个 |
| 「xxx.wav not exists」 | 原声的路径写错了，核对一下文件放在哪 |
| 「参考音频在3~10秒范围外」 | 原声太长或太短，剪到 3 到 10 秒 |
| 念出来有电子音 | 原声太短了，换 5 到 10 秒的 |
| 第一句要等很久 | 第一次会慢一些，后面就快了 |
| 每句都很慢 | 显卡被游戏或别的程序占着 |
| 某种情绪的语气不对 | 那段原声文件名里的原文，和它实际说的话对不上 |

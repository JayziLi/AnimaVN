# 接入语音

不接语音也能玩，只是角色不出声。想让角色念台词，要先接一个语音服务：有 NVIDIA 显卡就用 GPT-SoVITS，没有就用 Fish Audio 或者中转站。

## 要准备

用 GPT-SoVITS：

- 一台有 NVIDIA 显卡的电脑，可以就是你玩的这台
- 一个文件夹，放角色的声音模型和原声：
  - 模型：一个 `.ckpt` 文件和一个 `.pth` 文件。网上有别人练好的，也可以用 GPT-SoVITS 自己练
  - 原声：每种情绪一段，每段 3 到 10 秒。文件名写成 `【情绪】原文.wav`，比如 `【害羞】べ、別に待ってたわけじゃないから….wav`。文件名里的原文要和音频里说的一字不差

情绪名尽量和立绘的表情名一样。比如立绘叫「害羞」，原声也用「害羞」，念台词的语气就会跟着表情变。

用 Fish Audio：一个 API Key，和上面那样的原声（不用模型）。

用中转站：地址、API Key 和音色名，不用模型和原声。

## 第 1 步：装好 GPT-SoVITS

用 Fish Audio 或中转站的，跳到第 2 步。

1. 到 [GPT-SoVITS 的 Releases](https://github.com/RVC-Boss/GPT-SoVITS/releases) 下载 Windows 整合包。RTX 50 系显卡选名字带 `nvidia50` 的那个
2. 解压到路径里没有中文和空格的地方，比如 `D:\GPT-SoVITS`
3. 双击 AnimaVN 里的 `tools\voice-helper\install\装到GSV里.bat`（整合包在 `语音小插件\install\`），选刚解压的文件夹。问「别的电脑也要连这台吗」时，只在这台玩就选 N
4. 桌面上多了「启动 AnimaVN 语音」，双击它。用浏览器打开 <http://127.0.0.1:9880/docs>，能打开就说明启动好了

以后每次玩之前都要先开着它。

## 第 2 步：连上语音服务

游戏里按 Esc → 插件，点左边「全局」里的「语音服务」。

1. 填名称，「类型」选你用的服务
   - GPT-SoVITS：地址不用改，配对码空着
   - Fish Audio：地址留空，填 API Key
   - OpenAI 兼容（中转站）：填地址和 API Key，点「刷新列表」选模型，再点「+ 加音色」填音色名
2. 点「保存」，再点右边的「连接」。显示「通了」就接上了

## 第 3 步：导入角色的声音

中转站的音色上一步已经加好了，跳到第 4 步。

游戏里按 Esc → 素材，点上面的「声音」。

1. 点右上角的「导入」，选「选文件夹」，选放模型和原声的那个文件夹
2. 看一眼认出来的模型和情绪，「挂到」选要用的连接，点「导入」。文件会自动准备好
3. 试听：在「试听」那里输一句台词，选一个情绪，点「合成」。哪个语气不对，就换那段原声。想调语速，在右边的「全局参数」里

排第一的情绪是默认语气，默认用名字叫平静、默认、日常的那段。

## 第 4 步：给这张卡选音色

进游戏，点右下角的语音图标，在「音色」那一行选。一张卡只用一个音色，选了就换掉原来的。

然后角色的台词就有声音了。旁白和你自己说的话不念。

音色的语言是日语，就自动变成日语配音、中文字幕，不用另外设置。只想看中文：游戏设置 → 文字 → 字幕，选「只显示中文」。

没选音色的卡也想出声：插件 → 语音服务，左下角「没配声音的卡」选一个声音。

## 语音在另一台电脑上

玩的电脑显卡不够、家里另一台有显卡的话，可以在那台上启动 GPT-SoVITS，再连过来。推荐用 Tailscale：

1. 两台电脑都装 [Tailscale](https://tailscale.com/)，登同一个账号
2. 在显卡那台装好 GPT-SoVITS（第 1 步），问「别的电脑也要连这台吗」时选 y，记下显示的配对码。启动窗口里也写着
3. 在显卡那台运行 `tailscale serve --bg --tcp=9880 tcp://127.0.0.1:9880`
4. 在 AnimaVN 的 插件 → 语音服务 里，地址填 `http://显卡那台的名字.你的tailnet.ts.net:9880`，再填配对码

导入的声音会自动送到那台电脑，不用手动拷文件。

## 常见问题

| 你看到的 | 怎么办 |
|---|---|
| 语音面板写着「连不上了」 | GPT-SoVITS 没开，或者地址不对。用浏览器打开 `地址/docs` 看看 |
| 语音面板写着「语音已关闭」 | 把面板里的「语音」开关打开 |
| 角色不出声 | 这张卡还没选音色，照第 4 步选一个 |
| 测试写着「配对码没填或不对」 | 填 GPT-SoVITS 启动窗口里的配对码。同一台电脑不用填 |
| 导入时 GPT-SoVITS 那行是灰的，写着「没有模型」 | 文件夹里没有 `.ckpt` 和 `.pth`，挂到 Fish Audio 或者 IndexTTS |
| 「参考音频在3~10秒范围外」 | 原声太长或太短，剪到 3 到 10 秒 |
| 念出来有电子音 | 原声太短了，换 5 到 10 秒的 |
| 第一句要等很久 | 第一次会慢一些，后面就快了 |
| 每句都很慢 | 显卡被游戏或别的程序占着 |
| 某种情绪的语气不对 | 那段原声文件名里的原文，和它实际说的话对不上 |

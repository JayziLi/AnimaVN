# 接入生图（BETA）

聊到想留个画面的地方，点一下输入框旁边的画笔，就能给这一幕画一张插图，像 galgame 里的 CG。

三种画法选一种接上就行：

- **NovelAI**：要订阅，画二次元最省心
- **中转站**：填地址和 key，能用 gpt-image、Gemini 这类模型，按站点的价格花钱
- **本地 SD**：连你自己电脑上的 A1111 或 Forge，不花钱，要显卡

## 要准备

- 上面三种里的一种。NovelAI 推荐最高的 Opus 档，用 V4.5 模型画不限张数。其它档位也能用，但每张都要扣 Anlas（NovelAI 的点数）
- 一个便宜、快的聊天模型，比如 DeepSeek，用来把剧情写成「这一幕画什么」，设置里叫它「指导模型」。也可以直接用你聊天的那个模型，只是会慢一些、贵一些

## 先看一下花费

- 自动出图默认开着：每条回复写完，AI 都会判断要不要配图。不是 Opus 的话（中转站也一样），建议先到「自动出图」页关掉，想画的时候再手动点
- 默认的画图模型是 V5。Opus 用它每天有一定额度，用完就开始扣 Anlas。想不限张数，到「画面」页把模型换成 V4.5
- 换成 V4.5 以后要留意「角色」页的参考图：它默认是「用立绘」，让 AI 照着立绘画，长相更稳，但每张多扣 5 Anlas，Opus 也扣。想一分不花，把它改成「不用」
- 默认尺寸在免费范围内。调大了要扣 Anlas，还得先在「画面」页的「更多」里打开「允许超出免费范围」才画得了

还有一点：AnimaVN 没有登录密码。同一个 Wi-Fi 里的人知道你的地址，就能用你的 token 画图。在宿舍、公司这种公共网络里玩要注意。

## 接入步骤

1. 接一条画图连接，看下面对应的小节
2. 在「连接」页下面的「指导模型」里，选你准备好的聊天模型，思考保持「关」
3. 到「画面」页选这张卡用哪条连接，点「测试出图」，能出图就接好了
4. 到「角色」页填角色的样子。原作角色在「角色名」填英文名标签，比如 `keqing (genshin impact)`；原创角色在「长相」写英文描述，比如 `adult, long black hair, ponytail, brown eyes`。不想自己写，就点「让指导模型读卡写一版」
5. 进游戏聊几句，点输入框旁边的画笔，等 10 秒左右就能看到图

右键（手机上长按）画笔，可以先写「想看什么」再画，比如「她换上泳装」。

图出来以后点「收藏」，它就成了这张卡的 CG，之后聊天时 AI 会自己把它拿出来用。

## 接 NovelAI

1. 登录 [novelai.net](https://novelai.net)，左下角设置 → Account → Get Persistent API Token，复制那串 `pst-` 开头的字。这就是你的 token，别发给别人
2. 游戏里打开菜单 → 设置 → 最后一页「AI 生图」→ 连接 → 加一条连接，选 NovelAI，贴上 token，点「连接」。能看到你的订阅档位，就说明接上了

## 接中转站

1. 在「连接」页点「加一条连接」，选中转站，填地址（比如 `https://你的中转站/v1`）和 key，点「连接」
2. 到「画面」页选模型。列表里没有的可以点「手填」
3. 点「测试出图」。按钮上写着要花钱，点一次按站点的价格扣一张

一般这样就能用。站点不一样的地方，在「连接」页点开这条连接改：

- **接口**：默认「自动」，会自己试。站点只开了某一种时选那一种
- **可用尺寸**：模型只收固定几种尺寸时填这里，画的时候换成最接近的一种。默认填的是 gpt-image 收的那三种，用别的模型可以清空
- **额外参数**：填一段 JSON，比如 `{"quality": "low"}`，原样发给站点

「角色」页的参考图默认是立绘：图会和文字一起发给模型，长相更稳，但一般更贵。想省钱把它改成「不用」。

## 接本地 SD

要准备：一张能跑 Stable Diffusion 的显卡，和你想用的模型文件。

1. 装 [Forge](https://github.com/lllyasviel/stable-diffusion-webui-forge) 或 [A1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui)，先确认它自己的网页能画图
2. 启动参数加上 `--api`（Forge 和 A1111 都是在 `webui-user.bat` 的 `COMMANDLINE_ARGS=` 后面加），重启
3. 在「连接」页点「加一条连接」，选本地 SD，点「找一找」。服务开在别的电脑上就自己填地址，比如 `http://192.168.1.10:7860`，那台电脑的启动参数还要加 `--listen`
4. 到「画面」页选这条连接，选模型。「LoRA」那一行点 `+` 选要用的，点一下标签开或关，`⋯` 里改权重、填触发词
5. 点「测试出图」，能出图就接好了

步数、采样器这些在「更多」里，不选就用服务自己的设置。

LoRA 是每张卡各存一份的，右键画笔也能开关。用 ComfyUI 这类软件的话，要自己包成同样的接口，格式写在 [image-gen-api.md](image-gen-api.md)。

常见问题：

| 你看到的 | 怎么办 |
|---|---|
| 「连不上 … 服务没开」 | Forge 没启动，或者端口不是 7860 |
| 「机器没开机，或者不在同一个网络」 | 服务开在别的电脑上时，看那台电脑开着没、地址对不对，启动参数有没有 `--listen` |
| 模型、LoRA 的下拉没有内容 | 启动参数没加 `--api`，或者服务还没开好，等它开好点「重新拉取」 |
| 新放进去的 LoRA 找不到 | 点 `+`，再点「刷新」 |
| 第一张很慢 | 第一次要把模型读进显卡，一般半分钟左右，之后就快了。换模型时也要等一次 |
| 画一张都很慢 | 显存不够，或者别的程序占着显卡。把尺寸调小或者关掉别的程序试试 |
| 画的时候看不到模糊的预览 | 不影响出图。Forge / A1111 的设置里把 Live previews 打开 |

## 常见问题

| 你看到的 | 怎么办 |
|---|---|
| 「还没填 NovelAI token」 | 回到「连接」页把 token 填上 |
| 「这条中转站还没选模型」 | 到「画面」页选一个模型 |
| 中转站回 401 / 402 / 429 | 分别是 key 不对、余额不够、太频繁，去站点后台看 |
| 中转站回 404，换了接口也不行 | 站点不支持这个模型出图，换一个模型 |
| 「接口没有回图片」 | 选的是只能聊天的模型，换一个能出图的 |
| 「NovelAI token 无效或过期了」 | 照接入步骤第 1 步重新拿一个 token 填进去 |
| 「NovelAI 的 Anlas 不够了」 | 今天的额度用完了，或者尺寸太大，或者开着参考图。把模型换成 V4.5、参考图改成「不用」，或者把尺寸调回默认 |
| 「连不上 NovelAI」 | 网络问题，国内一般要开代理 |
| 「指导模型…出错」 | 写画面的那个聊天模型连不上，去 API 设置里测试一下它 |
| 画出来的人不像 | 把角色名、长相写得更具体，或者用 V4.5 加参考图 |

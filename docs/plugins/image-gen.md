# 接入生图（BETA）

聊到想留个画面的地方，点一下输入框旁边的画笔，就能给这一幕画一张插图，像 galgame 里的 CG。

现在只支持 NovelAI，要花钱。

## 要准备

- NovelAI 的订阅。推荐最高的 Opus 档，用 V4.5 模型画不限张数。其它档位也能用，但每张都要扣 Anlas（NovelAI 的点数）
- 一个便宜、快的聊天模型，比如 DeepSeek，用来把剧情写成「这一幕画什么」，设置里叫它「指导模型」。也可以直接用你聊天的那个模型，只是会慢一些、贵一些

## 先看一下花费

- 自动出图默认开着：每条回复写完，AI 都会判断要不要配图。不是 Opus 的话，建议先到「自动出图」页关掉，想画的时候再手动点
- 默认的画图模型是 V5。Opus 用它每天有一定额度，用完就开始扣 Anlas。想不限张数，到「画面」页把模型换成 V4.5
- 换成 V4.5 以后要留意「角色」页的参考图：它默认是「用立绘」，让 AI 照着立绘画，长相更稳，但每张多扣 5 Anlas，Opus 也扣。想一分不花，把它改成「不用」
- 默认尺寸在免费范围内。调大了要扣 Anlas，还得先在「服务」页打开「允许超出免费范围」才画得了

还有一点：AnimaVN 没有登录密码。同一个 Wi-Fi 里的人知道你的地址，就能用你的 token 画图。在宿舍、公司这种公共网络里玩要注意。

## 接入步骤

1. 登录 [novelai.net](https://novelai.net)，左下角设置 → Account → Get Persistent API Token，复制那串 `pst-` 开头的字。这就是你的 token，别发给别人
2. 游戏里打开菜单 → 设置 → 最后一页「生图」→ 服务，把 token 贴进去保存。点「查额度」，能看到你的订阅档位，就说明接上了
3. 在同一页的「指导模型」里，选你准备好的聊天模型，思考保持「关」
4. 到「角色」页填角色的样子。原作角色在「角色名」填英文名标签，比如 `keqing (genshin impact)`；原创角色在「长相」写英文描述，比如 `adult, long pink hair, side braid, purple eyes`。不想自己写，就点「让指导模型读卡写一版」
5. 进游戏聊几句，点输入框旁边的画笔，等 10 秒左右就能看到图

右键（手机上长按）画笔，可以先写「想看什么」再画，比如「她换上泳装」。

图出来以后点「收藏」，它就成了这张卡的 CG，之后聊天时 AI 会自己把它拿出来用。

## 常见问题

| 你看到的 | 怎么办 |
|---|---|
| 「还没填 NovelAI token」 | 回到「服务」页把 token 填上 |
| 「NovelAI token 无效或过期了」 | 照接入步骤第 1 步重新拿一个 token 填进去 |
| 「NovelAI 的 Anlas 不够了」 | 今天的额度用完了，或者尺寸太大，或者开着参考图。把模型换成 V4.5、参考图改成「不用」，或者把尺寸调回默认 |
| 「连不上 NovelAI」 | 网络问题，国内一般要开代理 |
| 「指导模型…出错」 | 写画面的那个聊天模型连不上，去 API 设置里测试一下它 |
| 画出来的人不像 | 把角色名、长相写得更具体，或者用 V4.5 加参考图 |

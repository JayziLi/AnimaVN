# 界面原型

都是静态原型,没接进游戏。图片直接引用 `userdata/blobs/`,离开仓库目录就显示不出来。

**对比页**:`index.html` 把下面所有原型缩小摆在一页(每张卡里跑的就是原型本身),`current/` 是游戏现状的截图,`refs/` 是参考官网的截图。要用 http 打开:仓库根目录跑 `python -m http.server 8765`,再开 `http://127.0.0.1:8765/docs/design/`。单个原型双击也能看。

| 目录 | 是什么 | 状态(2026-09-30) |
| --- | --- | --- |
| `login/` | 公网试玩版的登录 / 注册页 | 已定:只用景色 |
| `home/` | 宣传站式的主界面:顶栏 + 一屏一段(主页 / 角色 / 场景 / 存档) | 用户:「不错,很有感觉,但比较适合作为宣传网站」—— 留着 |
| `game/` | 游戏内四屏:启动 / 进入 / 选角色(斜切长条)/ 加载 | 用户:「好看,作为一个备选;但不 galgame,像角色宣传界面」—— 留作备选 |
| `galgame/` | 把 `home/` 的主界面改成 galgame 标题画面的样子(明亮 CG + 竖排菜单 + 右下对话框) | v1 用户:「百分之 50 的对」;10-01 又说「这个风格是对的」,但角色选择不能放在标题上、太单调 → `v2.html`:角色选择挪成菜单项、单独一页;加斜切(星夜 / 纸面两种,顶上可切) |
| `split/` | 照 Astrae Oratio 官网角色页:一道斜线切两半,深色侧是放大的脸 + 立绘 + 星芒,纸面侧是名字和按钮,最边上一列角色选择;右上角可镜像。`saves.html` 是存档页:照同一个官网的新闻卡片(胶囊筛选 + 错位细框 + 斜切卡图) | 进行中 |

`home/assets/`(logo、字标)和 `home/data.js`(演示数据)其余几个目录共用。

## 画布(2026-10-02 起的主工作台)

定下来的方向搬到了 claude.ai 的 Design 画布上:https://claude.ai/artifact/4EhfKy91LVrMDyEGm3EQzd(私有)。`canvas/project/` 是画布的源文件(`canvas.json` 索引 + 每张画板一个 `.dc.html`),`canvas/assets/` 是传上去的素材原件(压缩过的立绘、场景、头像、星空 SVG),`canvas/shots/` 是备选方案、参考和现状的截图(画布上这些是图片画板,不能编辑)。画布分三页:定稿方向 / 备选方案 / 参考与现状。改画板就改这里的文件再发布到同一个链接。

2026-10-03 新加一页「存档 · 设置 · 其他界面」(11 块,`Menu-*.dc.html`):存档 A/B/C、设置 A/B/C、历史 A/B、暂停菜单、插件这类长页、加载,风格接选角色页选中的 E3 / E4。画板由 `refs/menus/gen.py` 生成(改设计改它再跑),内容是本机库里星绘真实的存档和对话(只读导出到 `refs/menus/data.json`);截图和本机看图页在 `refs/menus/shots/`、`refs/menus/review.html`。新传的素材(星绘场景包另三张、八种表情头像、温柔 / 害羞全身立绘)登记在 `canvas/pick/blobs.json`。

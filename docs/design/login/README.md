# 登录 / 注册页原型

公网试玩版的登录页。构图和标题画面的海报一样：斜切两块，上面是场景，下面是纸面，中间一条强调色细线。手机切成上下两块，桌面（宽 ≥ 820 且横屏）切成左右两块。

只放景色、不放立绘：两版做出来对比过，用户选了单纯景色（2026-09-28）。

- `index.html`：登录页本身。双击就能打开，每次随机换一张场景；右上角「演示」可以切换状态和场景
- `preview.html`：所有状态并排放（手机 5 种状态、8 张封面，外加桌面 4 格）
- `login.css`：组件样式，类名都以 `au-` 开头
- `demo.js`：演示用的封面数据和状态切换，改 React 时换掉

图片直接引用 `userdata/blobs/` 里的文件，没有复制，所以离开这个仓库目录就显示不出来。

## 封面变量

| 变量 | 说明 |
| --- | --- |
| `bg` | 场景背景（横图） |
| `focus` | 竖屏时横向对准哪儿（场景的 `focus_x`） |

照片上只放左上角的 ANIMA 字标，不写地点和作品名（2026-09-28 用户要求去掉）。`demo.js` 里的 `place` 只是演示开关的按钮名。

强调色写在根元素上：`--au-acc`（亮的：斜线）、`--au-acc-deep`（深的：按钮、焦点、选中）。原型里的值是离线用 `accentOf` 同一个算法从背景算好的，因为双击打开时浏览器不让 canvas 读本地图片的像素。

封面池挑了冷暖各半的 8 张。樱花河堤取出来是金色、和樱花对不上，没放进来；以后加场景也先看一眼取出来的颜色。

## 状态

都写在根元素 `.au` 上：

- `data-mode="login"` / `"register"`：注册时「再输一次密码」从 0 高展开，纸面和斜线跟着往上长
- `.is-busy`：提交中。输入框只读，按钮上羽毛摆动，底边走进度条
- 出错：`.au-msg` 里写字（按钮上方一直留着这一行，出错时按钮不跳）。前端校验能指出是哪一栏的，就给那一栏的 `.au-field` 加 `.is-invalid`；服务器回的错只写字

## 改成 React

- 强调色：`frontend/src/debug/vn/titleArt.ts` 的 `accentOf(背景)`，取不到时用 CSS 里的默认值
- 校验和文案照 `feat/public-play` 分支的 `LoginPage.tsx`
- 那个分支的登录页注释写着「没登录拿不到场景包素材」：随机封面需要一个不用登录的接口（只返回背景和 focus，图片走带 `?w=` 的缩略图），或者把几张背景打包进前端。现在只要背景，打包进前端也不重
- 字体原型里从 Google Fonts 加载；游戏里的 `vnTitle.css` 只写了字体栈（思源宋体、宋体兜底），国内打不开 Google Fonts 时会用兜底字体

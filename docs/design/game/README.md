# 加载 / 进入 / 选角色 原型

游戏里的几屏(宣传站式的那版在 `../home/`)。`index.html` 双击打开,顶上中间可以直接跳到某一屏;地址后面加 `#title` / `#select` / `#gate` 也行。

参考(2026-09-30 实际打开看过):星铁、绝区零、鸣潮官网的角色页,Astrae Oratio、蔚蓝档案的首屏。
- 鸣潮:左边一列阵营图标,右边一排竖长的角色立绘条
- 绝区零:斜切的色块、平行四边形的缩略图和按钮、大名字 + 一句台词
- 星铁:左边阵营竖排(一条线串着)、名字 + 台词叠在立绘旁

四屏:
1. 启动:logo → 字标,底下一道横贯整屏、微微往右下斜的流星当进度,星星是头
2. 进入:上下黑边的片头构图。上次停下的场景 + 当前角色立绘 + 大 logo + 「点击任意位置进入」;底边左侧是「现在是谁 · 上次什么时候 · 换角色」,右侧读档 / 设置 / 调试台
3. 选角色:左边按作品分组(卡片的第一个标签),右边一排斜切长条,每条是那个角色的立绘 + 她上次的场景;选中的展开,露出作品名、名字、标签、上次的最后一句、接着上次 / 新的故事。← → 换人,Enter 进入,Esc 返回
4. 进游戏前的加载:上次的场景虚化垫底,拱形头像 + 名字 + 上次的最后一句;底下同一道流星进度,左边是真实的素材计数,右边一条小提示

数据、logo、字标都引用 `../home/` 里的(`data.js`、`assets/`)。「3 小时前」和台词是演示用的假数据。竖屏只做了兜底。

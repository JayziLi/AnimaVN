# 启动画面 + 主界面原型

`index.html` 双击就能打开(`?skip` 跳过启动直接看主界面)。右下角可以重放 / 跳过启动。

参考的是游戏官网首页的排法(2026-09-30 实际打开看过 Astrae Oratio、蔚蓝档案、鸣潮的官网):顶栏常驻(小字标 + 分区标签,当前分区前面亮一颗星)、首屏整幅主视觉 + 大 logo + 左下按钮组 + 右下横幅卡片、往下一屏一段(角色:斜切两半 + 大立绘 + 拱形头像;世界:斜切卡片轮播)、段标题下面一条星星花边。

- 启动:logo → 字标 → 一道往右下坠的流星当进度(字标里那道)。只写「正在准备」,不放数字
- 主页:上次停下的场景 + 当前角色立绘;左下「继续」(带那一幕的缩略图)、新的故事、读档;右下最近的两段
- 角色:左边深色斜切放立绘,右边纸面放作品名、名字、标签、上次的一句、拱形头像列
- 场景:当前角色场景包里的地点,斜切纸角写地名
- 存档:最近的几段

文件:`home.css` 样式,`home.js` 演示逻辑,`data.js` 演示数据(从 `userdata/tables` 抄的几张卡;图片直接引用 `userdata/blobs/`,离开仓库目录就显示不出来),`assets/` 里是 logo 和字标。

字标 `assets/wordmark.png` 是 GPT 出的位图抠的(桌面 `logo设计\过程稿\7-艺术字\wordmark_AH`),还没转 SVG,只能放在深色底上。

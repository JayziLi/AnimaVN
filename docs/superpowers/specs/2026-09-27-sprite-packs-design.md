# 立绘包（一整套立绘，可以嫁接给任何角色）

状态：已实现，老表待清（用户 2026-09-27 确认设计）
日期：2026-09-27

## 目标

用户原话：「我们做两个立绘包，因为立绘包绑定角色卡，玩家可以局内随时切换」「我的立绘包的意思是：一整套的立绘，可以嫁接给任何一个角色」。

1. 立绘从「挂在某张卡上」改成独立的**立绘包**：一个包是一整套表情立绘（名字、别名、说明、图、找脸结果），和场景包一样不属于任何一张卡
2. 任何一张卡都能挂一个或几个立绘包；同一个包可以挂在好几张卡上（比如香奈美的舞台装也能给别的卡用）
3. 游戏里随时切换这张卡用哪个包

第一个用上它的是香奈美：舞台装「夜莺」、私服「花的私语」两个包。

## 已定的决定

| 项 | 决定 | 来源 |
|---|---|---|
| 包和卡的关系 | 包独立存在；卡和包是多对多，一张卡挂几个包、排好顺序，其中一个是「当前」 | 用户：「可以嫁接给任何一个角色」「局内随时切换」 |
| 切换记在哪 | **跟着卡走**：换了以后这张卡所有对话、存档都用新的包，直到再换回来 | 用户选的（2026-09-27） |
| AI 知不知道 | **完全不告诉 AI**：只换图。提示词、`{{sprites}}` 列的表情名照旧来自当前包 | 用户选的 |
| 表情名 | 名字、别名只在一个包里唯一（原来是在一张卡里唯一）。几个包最好用同一套表情名，语音的情绪行按名字对得上；不全的包照样能用（对不上名字的交给表情模型挑最像的，和现在一样） | 沿用现有规则 |
| 当前包存哪 | 存在后端（卡和包的绑定表上），不放前端的设置里 | 标题画面要给每张卡取「当前包」的脸，后端得知道 |
| 位置微调（`CardSpriteLayout`） | 改成**跟着包走**：微调补的是这套图本身的构图，包换到别的卡上也该带着 | 图决定构图；卡级别的「人物大小、头的高度」本来就在全局配置里 |
| 复制卡 | 复制绑定（指向同样的包），不再深拷贝图 | 和场景包一样；省空间 |
| 删卡 | 只删绑定，包留着（插件页能看到「没有卡在用」的包，手动删） | 包可能还挂在别的卡上 |
| 删包 | 删掉包里的立绘和所有绑定；卡的当前包指着它的，换成它下一个挂着的包，都没有了就是「没有立绘」 | |
| 老数据 | 迁移脚本把每张卡现有的立绘变成一个包（包名 = 卡名，重名加后缀），挂到这张卡上并设为当前；两张卡的立绘一模一样（复制出来的卡）时共用一个包；「一模一样」= 名字、别名、说明、顺序、开关、图，外加位置微调都相同（微调不同还共用，会有一张卡的位置变掉） | 现在库里 12 张卡、150 条立绘，其中 30 张图是复制卡时重复的 |

## 数据

- 新表 `sprite_packs`：`id`、`name`（全局唯一）、`description`、`created_at`、`updated_at`
- 新表 `pack_sprites`：和现在的 `card_sprites` 一样的列（`label`、`aliases`、`description`、`image`、`mime`、`sort`、`enabled`、`face_scan`），只是 `card_id` 换成 `pack_id`
- 新表 `card_sprite_packs`：`card_id`、`pack_id`（联合主键）、`sort`、`is_current`
- 新表 `sprite_pack_layouts`：`pack_id` 主键，列和现在的 `card_sprite_layouts` 一样
- 老表 `card_sprites`、`card_sprite_layouts` 迁移后不再使用，**先不删**，等用户确认新的没问题后再清（迁移前照例备份数据库）
- 迁移脚本 `AnimaBackend/scripts/migrate_sprite_packs.py`：可以重复跑（已经迁过的卡跳过），测试写进 `tests/test_migration_scripts.py`

## 接口

- 立绘包：`GET/POST /api/sprite-packs`（列表带立绘数、在用的卡数），`PUT/DELETE /api/sprite-packs/{pack_id}`（改名、说明 / 删除）
- 包里的立绘：现在 `/api/tavern/cards/{card_id}/sprites/...` 下的所有操作（增删改、排序、上传图、找脸、位置微调）原样搬到 `/api/sprite-packs/{pack_id}/sprites/...`
- 卡挂哪些包：`GET /api/tavern/cards/{card_id}/sprite-packs`（按顺序，带哪个是当前），`PUT` 整组替换（和 `CardVoice` 的做法一样），`PUT .../current` 只换当前包
- 保留按卡读的几个接口，内部解析成「这张卡的当前包」：
  - `GET /api/tavern/cards/{card_id}/sprites`：当前包的立绘列表
  - `GET .../sprites/face`：标题画面的头像圈
  - 立绘图的地址改成按包取（`/api/sprite-packs/{pack_id}/sprites/{id}/image`）
- 语音「按立绘表情补齐」：用这张卡当前包的立绘

## 界面

- **插件页 · 立绘**（调试台抽屉和游戏菜单是同一个组件）：
  - 上面一条「这张卡的立绘包」：挂着的包按顺序排，标出当前的；可以加一个已有的包（任何卡的都行）、新建空包、从卡上拿掉、改名、删包（提示有几张卡在用）
  - 下面的表情表格和位置微调编辑选中的那个包，用法和现在一样
  - 实现时的取舍：「选中编辑的包」就是当前包——点哪个包就换成哪个包，不另存一份「正在编辑」的状态。新挂上 / 新建的包直接成为当前包
- **游戏里切换**：游戏菜单「角色」页加一行「立绘包」，点一下就换，立绘当场换成新包里同名的表情（这一行在「绑定」栏里，和玩家身份、预设放一起，调试台的角色卡编辑器里也有）
  - 下拉框列出**所有**立绘包：这张卡挂着的在前（「这张卡的」），其他包在后（「其他立绘包」）；选了其他包就挂到这张卡的包后面并设为当前。2026-09-27 用户看了只列挂着的包的版本后说：「素材包是一个，比如阿米娅的立绘是一个素材包，香奈美 · 花的私语是一个，香奈美 · 夜莺也是一个」—— 每套立绘就是一个素材包，哪张卡都能直接选，不用先去插件页挂
- 标题画面的头像圈、主色、蒙太奇都跟着当前包走

## 已知的代价

- 存档缩略图用的是当前包的立绘（存档不记当时穿的哪套）——用户选了「跟着卡走」，这是预期行为
- 同一个包挂在几张卡上时，在插件页改它（改名字、禁用、换图）几张卡都会变。页面上会提示「有 N 张卡在用这个包」（场景包也是这么提示的）
- 找脸找不到的立绘（侧脸、手挡住脸）借同尺寸别的立绘的脸框对齐，多姿势那种一张一个构图的包，这几张可能对得不太准

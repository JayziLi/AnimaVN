# Windows 整合包

2026-10-17。做法和打包命令见 `packaging/windows/README.md`，这里只记为什么这么做、定了什么、测出来什么。

## 起因

国内朋友反映三件事：下载慢；依赖不打包，要自己装；安装步骤太繁琐。原来的装法是：装 Python 3.11 和 Node 22，安装 Python 时还得勾上 PATH；然后敲 6 条命令，从国外的源装几百 MB 依赖；最后再下情绪模型。代码放在 GitHub，国内下载慢；美国服务器之前国内实测只有 200–400 KB/s，也不适合放大文件。

## 用户定的

- 做整合包：解压后双击 `AnimaVN.bat` 就能玩，不用装 Python、Node、Git
- 下载放**魔搭 + GitHub**：魔搭给国内，GitHub 给海外和开着代理的人。GPT-SoVITS 官方整合包也是放魔搭直链，下载页写着国内「可满速下载」
- 用 **zip**：Windows 自带就能解；7z 能小 40 MB，但 Win10 要另装软件
- 带 **「更新.bat」**：只下代码，存档不动；运行环境变了才让玩家重下整合包

## 做法里的几个取舍

| 问题 | 怎么办的 | 为什么 |
|---|---|---|
| 玩家不装 Node | 前端提前打包成静态页面，用 `VITE_API_BASE_URL=""`，后端和页面走同一个端口 | 原来两个黑窗口变成一个；手机访问也只要一个地址 |
| 玩家不装 Python | 官方便携版 Python 3.11.9 + `pip install --target` | 3.11.9 是 3.11 最后一个带 Windows 二进制的版本，和开发用的 venv 一致 |
| 干净的系统缺 VC++ 运行库 | 把 `msvcp140.dll`、`msvcp140_1.dll` 放进 `python/` | onnxruntime 和 greenlet 要用；便携版只带了 vcruntime |
| Windows 自带解压太慢 | 外层只放 45 个文件，其余打成一个 `runtime.zip`，第一次启动时由 Python 解开 | 实测资源管理器 12 分钟只解开 851 个文件 |
| 第一次启动要编译几千个文件 | 纯 Python 的 29 个包连同编译好的 `.pyc` 放进 `python/site-packages.zip` | openai + anthropic 散着放，第一次导入就要 57 秒 |
| 依赖版本 | `requirements.lock` 固定版本；由 Python 版本、lock 和情绪模型算出运行环境指纹 | 指纹只在有意换版本时才变，玩家才不会被频繁要求重下整合包 |
| 同一份存档被两个后端打开 | `data/launcher.lock` 锁住；第二次双击直接打开已经在跑的那个；游戏开着时更新器拒绝更新 | 两个后端同时写一个 SQLite 文件会出事 |

## 实测（这台笔记本，开着 Defender）

| | 第一版试做 | 现在 |
|---|---|---|
| 整合包 | zip 156 MB（7z 级压缩约 116 MB） | 约 160 MB |
| 更新包 | — | 21 MB |
| 解压后 | 381 MB，5683 个文件 | 约 370 MB，第一次启动后约 2500 个文件 |
| 资源管理器解压 | 12 分钟只解了 851 个文件 | 2–5 秒 |
| 第一次启动 | 126–136 秒 | 85–117 秒（解压 15–28 秒） |
| 以后每次启动 | 15 秒 | 15 秒 |
| 更新（本机假源，21 MB） | — | 3 秒；存档数据库的 SHA-256 前后一致 |

第一次启动剩下的时间主要花在 numpy（17 秒）、PyAV（15 秒）、SQLAlchemy（12 秒）上：这几个库带编译好的 dll，Windows 第一次加载时要逐个检查文件。以后启动就快了，所以这部分没再往下压，只把提示改成「第一次要一两分钟」，等待时每 15 秒报一次进度。

验证过的：路径带中文和空格能跑；资源管理器解压后中文文件名正常；openai、anthropic 两个 SDK 从 zip 里加载，打到本机假接口，普通、流式、异步都正常；游戏的「测试连接」两种格式都通；更新时坏的源会被跳过；游戏开着时更新会被拒绝；GitHub 上还没有发布时更新器会报错，存档不动。

没验证的：没装过 VC++ 运行库的干净系统（这台机器装着）；从国内实际下载的速度。第一版发给那位国内朋友试。

- 第一次正式发布：先发公开版，再在公开版目录里打包，传 GitHub（先建草稿，传完再公开）和魔搭；README 加「下载整合包」一节（链接上线了才写）
- 以后可以做：立绘对脸用的 OpenCV（110 MB）和音频转码用的 PyAV（63 MB）改成用到才下，整合包能降到 100 MB 左右；运行环境变了时让更新器自动换，不用玩家手动拷 data

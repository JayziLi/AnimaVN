# 二游式启动器(2026-10-20)

## 起因

`start.bat` 一双击跳 3 个黑窗口(bat 自己、后端、前端);整合包的 `AnimaVN.bat` 是 1 个黑窗口 + 浏览器,更新还要另外双击「更新.bat」。黑窗口不光难看:关错一个游戏就断了,出了错玩家只能截一屏英文。用户要「参考绘世 SD 启动器,做二游启动器的感觉」,截图是米哈游的 HoYoPlay 启动器。

## 做法(推荐,用户没反对)

- **窗口**:pywebview + Windows 自带的 WebView2,启动器界面就是网页,直接用纸面风格的底稿。游戏窗口是 pywebview 开的第二个窗口(全屏、没有地址栏)
- **双击入口**:带 logo 图标的 `AnimaVN.exe`(用 Windows 自带的 `csc.exe` 编一个几 KB 的小程序,只做一件事:用 `python\pythonw.exe` 跑启动器,所以没有黑窗口)。没签名,第一次双击 Windows 可能弹「已保护你的电脑」
- **托盘**:pystray(菜单和通知是 Windows 原生样式)
- **后端**:启动器开一个不带窗口的子进程跑后端,输出接进控制台页;「显示终端窗口」打开时照以前另开一个黑窗口
- **开发模式**(只在源码文件夹里出现):打包版(以前的 play.bat)/ 开发版(以前的 start.bat,多一个前端日志页签)
- **更新**:并进启动器(开始按钮上方提示「有新版本」→ 更新 → 重新打开),`更新.bat` 的逻辑照用
- **代价**:新依赖 pywebview(带 pythonnet、clr_loader、cffi、pycparser、bottle、proxy_tools)约 6.7 MB + pystray + qrcode;`requirements.lock` 一变运行环境指纹就变,老玩家要重下一次整合包(现在只发过 10-17 一版)

## 实验数据(10-20,笔记本)

| 测什么 | 结果 |
|---|---|
| 官方便携版 Python 3.11.9(和整合包同一个)跑 pywebview | 能跑,`pythonw.exe` 不弹黑窗口 |
| 双击到无边框窗口画出来 | 固定 `storage_path`:1.6–2.7 秒;pywebview 默认每次用临时配置(冷启动):5–13 秒 → **一定要固定配置文件夹** |
| 第二个全屏窗口(游戏窗口) | 0.2–0.4 秒 |
| JS ↔ Python 互相调、最小化 / 还原 | 都正常 |
| WebView2 运行时 | 本机 155;Win11 自带,Win10 一般随 Edge 装好了 |

坑:上一个实例刚关、WebView2 的后台进程还没退干净时,同一个配置文件夹会报 `0x800700AA`(资源正在使用),要等一下再重试。整合包里同一个文件夹只开一个启动器(已有 `launcher.lock`),第二次双击应该把已经开着的那个窗口叫到前面。

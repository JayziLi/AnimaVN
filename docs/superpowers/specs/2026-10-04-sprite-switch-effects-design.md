# 立绘切换特效、跳字音、字幕显示(2026-10-04)

参考碧蓝档案剧情:换表情时人物跳一下、头顶冒个气泡、响一声。用户 10-04 定的方案。

## 立绘切换特效

- **每张立绘单独设**(用户定的,不按情绪自动套):立绘包编辑页每行一个「切换特效」,三个下拉
  - 动作:跳一下 / 跳两下 / 左右晃 / 发抖 / 凑近 / 往后一缩 / 往下沉
  - 气泡:！ / ！？ / ？ / 爱心 / 害羞 / 怒筋 / 冒气 / 心烦 / 流汗 / 流泪 / 难过 / 叹气 / 灵光一闪
  - 音效:13 个气泡音 + 出现 1–3、卡通 1–2、摇头、发抖、泄气
  - 选了气泡而音效空着时,音效自动填上配对的碧蓝档案原声;「试一下」在缩略图上演一遍
- 存在 `pack_sprites.effect`(JSON,`{motion, bubble, sound}`,null = 没设)。值是前端清单
  `frontend/src/debug/plugins/spriteFx.ts` 的 id,后端只管存;前端不认识的 id 当没设。
  只改特效时不动 `updated_at`(图片版本号跟着它,变了浏览器要重新下载整张图)。
  老库跑 `AnimaBackend/scripts/migrate_sprite_effect_column.py`(公网服务器的库也要跑)
- **什么时候放**:这句是「往下读」到的(点下一句、自动播放、新回复跳过来),并且表情真的换了
  (同一句里后来才定下来的也算,比如问模型、Jev 判完)。往回翻、读档、历史里「回到这里」、
  跳过时都不放。等新立绘真的换上来(图下载完)才放,动作、气泡、音效一起出
- 动作用 Web Animations 播在立绘外面一层上(图自己的 transform 管定位);气泡按脸的位置摆在
  头的右上方(`spriteLayout.ts` 的 `bubbleStyle`),没认出脸的估一个位置。气泡是照碧蓝档案
  风格自己画的 SVG(`vn/SpriteBubble.tsx`),没用它的图
- 系统开了「减少动画」:不做动作,气泡只淡入,声音照放
- 设置「声音 → 音效」:立绘特效开关(默认开)、特效音量

## 跳字音

- 设置「声音 → 音效 → 跳字音」:关(默认)/ 柔和 / 8-bit / 轻点击(这三个现场合成)/ 可爱 / 啪 / 扣
- **只在旁白上响**,角色台词不管有没有配音都不响(用户选的 A);每隔一个字响一声,标点不响
- 要逐字显示才有跳字:文字速度是「瞬间」时这项变灰。**文字速度默认改成「瞬间」**(用户要的);
  之前存过设置的设备保留原来的速度

## 字幕显示

- 设置「文字 → 字幕」:日中双语 / 只显示中文。改的就是外语插件的「显示日语」(全局一份,
  存在后端 `plugin.lang`),和调试台插件里的开关是同一个,不另存一份

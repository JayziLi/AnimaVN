AnimaVN 架构

How it works

和酒馆一样，提示词在浏览器里组装；后端只做三件事：把请求转给模型、存数据、合成语音。语音、生图、Jev 都是可选的，不接也能玩。

浏览器
React + TypeScript + Vite
后端
Python + FastAPI + SQLite，跑在你的电脑上
外面的服务
自己选、自己填 key
写剧情

组装提示词

酒馆兼容层：角色卡、预设、宏、世界书，加上立绘 / 场景 / 语音这些插件自动补的说明，拼成一份完整的提示词。和酒馆 1.18 逐条对过答案。

演 出

一句一句演

回复边到边切成句子，像 galgame 一样点一下下一句。读每句前面的标签换表情、背景、曲子：
<sprite:微笑> <bg:客厅夜> <bgm:日常>

这一句
谁说的、什么表情

Jev 标注 可选 · 表情兜底

标签可以交给 Jev 判断：谁在说话、什么表情、要不要换场景。AI 写的表情名对不上立绘时，本地小模型 bge-small-zh（CPU 就能跑）挑最像的那张。

每句约 0.2 秒

Jev TypeSafe，可选

专门做判断的小模型

配 音

念台词

每句台词连同表情一起去要语音，可以日语配音、中文字幕。读到一半随时可以插话。

按表情挑这个声音对应情绪的参考音频，交给 GPT-SoVITS（也支持 IndexTTS）。合成过的句子存进缓存，重播不再花时间。

存 着

菜单和调试台

存档、历史、相册、素材、设置；调试台里改预设、看完整提示词。导入酒馆卡，或者把角色打包成 .animavn 带走。

读 / 写

数据

卡、预设、人设、存档放在 SQLite；立绘、背景、曲子、CG 按内容存成文件。都在 AnimaBackend/data/，升级前自动备份。

不上传，只存在你自己的电脑上

一条回复的路线　你说一句 → 浏览器组好提示词 → 后端转给模型 → 回复一句一句到 → 换表情、背景、曲子 → 去要语音、念出来 AnimaVN
